# Документация BotEngine

Документация описывает состояние текущей ветки репозитория.

## Руководства

- [Начало работы](getting-started.md) — клонирование, секреты, запуск примера и
  подключение платформ.
- [Конфигурация](configuration.md) — параметры Telegram, MAX, Redis и rate limiter.
- [Архитектура](architecture.md) — модули, жизненный цикл сообщения, команды,
  middleware и сессии.
- [Разработка](development.md) — команды сборки, Docker и типовые неисправности.
- [ADR](decisions/README.md) — принятые архитектурные решения.

Если поведение кода и текст руководства расходятся, это считается дефектом
документации. При изменении публичного API или конфигурационных ключей обновляйте
соответствующее руководство в том же изменении.
